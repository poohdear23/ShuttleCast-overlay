HOW TO

ใช้กับ PRISM Live Studio

  1. เครื่องนี้ (เครื่องควบคุม): ตั้งค่าแข่ง → สร้างห้องควบคุม → กด คัดลอกลิงก์
  2. ส่งลิงก์ให้เครื่องที่ถ่ายทอด (LINE / Messenger)
  3. PRISM: ปัดซ้ายที่หน้าพรีวิว → เมนู Web → วางลิงก์ → บันทึก
  4. ลากและย่อ/ขยายแถบคะแนนให้ไม่บังลูก แล้วกด Go Live
  5. กดคะแนนบนเครื่องนี้ จอไลฟ์เปลี่ยนตาม

ถ้าไม่เห็นแถบคะแนนใน PRISM: เช็กว่าเครื่องถ่ายทอดมีเน็ต และลิงก์ถูกต้องทั้งชื่อห้อง
